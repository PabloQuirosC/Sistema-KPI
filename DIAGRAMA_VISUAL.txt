═══════════════════════════════════════════════════════════════════════════════
                           RELACIONES PRINCIPALES
═══════════════════════════════════════════════════════════════════════════════

1. USUARIOS → ROLES (N:1)
   - Un usuario tiene un rol
   - Un rol puede tener muchos usuarios

2. USUARIOS → DEPARTAMENTOS (N:1)
   - Un usuario pertenece a un departamento
   - Un departamento tiene muchos usuarios

3. EMPLEADOS → USUARIOS (1:1)
   - Un empleado es un usuario
   - Un usuario puede ser un empleado

4. PROYECTOS → DEPARTAMENTOS (N:1)
   - Un proyecto pertenece a un departamento
   - Un departamento tiene muchos proyectos

5. TAREAS → PROYECTOS (N:1)
   - Una tarea pertenece a un proyecto
   - Un proyecto tiene muchas tareas

6. TAREAS → EMPLEADOS (N:1)
   - Una tarea está asignada a un empleado
   - Un empleado tiene muchas tareas

7. OBJETIVOS → PROYECTOS (N:1)
   - Un objetivo pertenece a un proyecto
   - Un proyecto tiene muchos objetivos

8. TAREAS → OBJETIVOS (N:1)
   - Una tarea puede estar vinculada a un objetivo
   - Un objetivo agrupa varias tareas

9. RESPONSABLES → USUARIOS (N:1)
   - Un responsable es un usuario con asignación especial
   - Un usuario puede tener varias responsabilidades


═══════════════════════════════════════════════════════════════════════════════
                              FLUJO DE DATOS
═══════════════════════════════════════════════════════════════════════════════

1. AUTENTICACIÓN Y PERMISOS
   ────────────────────────────
   USUARIOS → ROLES → PERMISOS

   El usuario se autentica → Se verifica su rol → Se obtienen sus permisos

2. GESTIÓN DE PROYECTOS
   ────────────────────────────
   DEPARTAMENTOS → PROYECTOS → OBJETIVOS → TAREAS → EMPLEADOS

   Departamento crea proyecto → Define objetivos → Crea tareas → Asigna empleados

3. SEGUIMIENTO DE TAREAS
   ────────────────────────────
   EMPLEADO → TAREAS → ACTUALIZACIÓN → PROGRESO OBJETIVO → PROGRESO PROYECTO

   Empleado trabaja en tarea → Actualiza estado → Calcula progreso objetivo →
   → Actualiza progreso proyecto

4. AUDITORÍA
   ────────────────────────────
   USUARIO → ACCIÓN → AUDITORIA

   Cualquier cambio en el sistema se registra automáticamente

═══════════════════════════════════════════════════════════════════════════════
                           MÉTRICAS CALCULADAS
═══════════════════════════════════════════════════════════════════════════════

PROYECTO:
  progreso = (tareas_completadas / total_tareas) × 100

OBJETIVO:
  progreso = (tareas_completadas / tareas_totales) × 100
  estado = automático según progreso y fechas

EMPLEADO:
  rendimiento = (tareas_completadas/total_tareas × 0.6) +
                (horas_trabajadas/160 × 0.4) × 100

  tasa_completado = (tareas_completadas / total_tareas) × 100

DEPARTAMENTO:
  empleados_count = COUNT(empleados activos)
  rendimiento_promedio = AVG(rendimiento empleados)
